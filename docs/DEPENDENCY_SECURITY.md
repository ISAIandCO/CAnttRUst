# Безопасность зависимостей

Runtime-зависимости проверяются в CI командой `npm audit --omit=dev --audit-level=high`. Они встраиваются в локальный background bundle; сетевой код зависимостей не используется.

На 25 августа 2026 года полный `npm audit` также сообщает GHSA-w3rx-r6r6-pgpr и GHSA-5p2g-fcmc-qvqq в `image-size <=2.0.2`, транзитивно используемом `addons-linter` из актуального `web-ext 10.6.0`. Исправленной версии в цепочке `web-ext` нет. Риск ограничен dev/CI: linter получает только отслеживаемые PNG проекта, а пакет `image-size` не попадает в XPI. Переход на устаревший `web-ext 5.5.0`, ошибочно предлагаемый `npm audit`, не принят. Исключение следует удалить сразу после выпуска исправления upstream.
