# Модель угроз

## Активы

- корректное решение, разрешать ли защищаемый CA для конкретного хоста;
- целостность отпечатка CA и ключей CT-логов;
- исходный URL и локальные исключения пользователя;
- релизный XPI и цепочка его сборки.

## Противники

- владелец или посредник, предъявляющий цепочку через Russian Trusted Root CA для имени вне российской зоны;
- издатель сертификата с отсутствующим, неизвестным, просроченным или некорректно подписанным SCT;
- страница, пытающаяся вызвать привилегированные сообщения warning/options UI;
- компрометированная зависимость или workflow, пытающиеся внедрить удалённый код в пакет.

## Контрмеры

- точное сравнение SHA-256 от DER по всей полученной цепочке;
- нормализация URL средствами платформы, punycode и проверка границы DNS-суффикса;
- строгий ограниченный парсер SCT/DER и локальная криптографическая проверка;
- sender-check для сообщений, короткоживущие непрозрачные event ID и точная привязка обхода;
- локальный CT-снимок с проверкой log ID = SHA-256(SPKI), операторов и интервалов;
- CSP, запрет dynamic code/remote script в CI, фиксированные версии npm и SHA GitHub Actions;
- XPI подписывает Mozilla; GitHub Release публикует контрольные суммы и исходный архив.

## Вне модели

- компрометация Firefox, ОС, аккаунта GitHub/AMO или закрытого ключа самого CT-лога;
- защита subresource-запросов и трафика других приложений;
- отозванные сертификаты и штатные TLS-ошибки — ими продолжает заниматься Firefox;
- TLS/OCSP SCT, которых нет во встроенном расширении сертификата.
