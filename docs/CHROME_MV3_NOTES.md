# Chrome / Manifest V3

Текущая реализация намеренно Firefox-only: она зависит от blocking `webRequest` для HTTPS-запросов и `webRequest.getSecurityInfo()` с цепочкой и raw DER. У Chrome MV3 нет эквивалентного API, позволяющего расширению синхронно получить TLS-цепочку и применить эту политику до передачи ответа странице.

Порт нельзя делать простой заменой manifest. Понадобится отдельный доверенный компонент (например, локальный proxy/native host или корпоративная политика), собственная модель угроз и отдельный пользовательский опыт. До появления подходящего браузерного API Chrome-сборка не планируется.
