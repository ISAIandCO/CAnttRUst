# ADR 0001: семантика `temporal_interval`

Статус: принято.

В формате CT log list `temporal_interval` описывает диапазон `notAfter` сертификатов, принимаемых конкретным временным шардом лога. Это не диапазон timestamp самого SCT.

Поэтому CAnttRUst выбирает лог по условию `start_inclusive <= certificate.notAfter < end_exclusive`. Timestamp SCT проверяется отдельно: он не должен быть позже `notAfter` сертификата или более чем на 24 часа в будущем относительно локальных часов.

Такое разделение следует семантике списка логов и не отклоняет корректные SCT, выданные до начала года для сертификата, срок которого попадает в годовой шард.
