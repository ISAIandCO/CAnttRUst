# Проверка

Локальный обязательный набор:

```bash
npm ci
npm run build:firefox
npm run check:reproducible
```

`build:firefox` включает проверку TypeScript, unit-тесты, сборку, валидацию CA/CT-политик, сканирование пакета и `web-ext lint` с предупреждениями как ошибками.

Перед релизом вручную проверьте распакованную сборку через `about:debugging`:

1. Обычный HTTPS-сайт с другой цепочкой открывается без вмешательства.
2. Цепочка через защищаемый CA вне `.ru/.su/.рф` показывает предупреждение.
3. Та же цепочка в разрешённой зоне без подходящего встроенного SCT блокируется.
4. «Продолжить один раз» разрешает ровно повторный переход в той же вкладке.
5. Исключения зоны и CT независимы; сессионные и часовые записи истекают, соседний поддомен остаётся защищён.
6. В приватном окне событие и bypass не пересекаются с обычным окном.
7. Экспорт/импорт настроек не принимает IP, URL и файл больше 256 KiB.

Для релизного workflow дополнительно проверьте SHA-256, версию `manifest.json` внутри XPI и факт подписи Mozilla в `about:addons`.


Дополнительные проверки обновлений: метаданные без релиза, изменения статуса/ключей,
пустые и неполные CT-списки, откат версии/времени, обязательный пригодный лог Яндекса,
сохранение старых корневых отпечатков, разбор официального PEM и отказ на повреждённых данных.
Процесс выпуска описан в [POLICY_UPDATES.md](POLICY_UPDATES.md).

## Автоматические проверки в настоящем Firefox

```bash
FIREFOX_BINARY=/path/to/firefox GECKODRIVER=/path/to/geckodriver npm run test:firefox
```

Требуются Firefox 142+, geckodriver, OpenSSL и Python 3. CI скачивает закреплённые Firefox 155.0.1 и geckodriver 0.36.0 с проверкой SHA-256. Тест создаёт одноразовый профиль, два локальных CA и TLS-сервера; тестовые корни импортируются только в этот профиль. TLS-проверка браузера остаётся включённой. В одноразовой копии сборки политика заменяется тестовым отпечатком; в релизный пакет эти ключи, разрешения на управление тестами и тестовый код не попадают.

Проверяются предупреждение при реальной TLS-цепочке, независимость исключений зоны/CT, отмена iframe/script/fetch, отсутствие исполнения скрипта, цепочка другого CA, HTTP→HTTPS redirect, повторная проверка закэшированного ресурса после отзыва исключения, диагностирование искусственного сбоя API, получение события страницей предупреждения и кнопка однократного продолжения.

Модульные тесты дополнительно проверяют срок исключений, приватную изоляцию, перезапуск, ошибки хранилища и конкурирующие записи, привязку сообщений к вкладке, границы памяти и устаревшие результаты навигации. Реальные исторические SCT проверяются отдельной криптографической фикстурой.

В контейнерах без user namespaces браузерный процесс может требовать `MOZ_DISABLE_CONTENT_SANDBOX=1 MOZ_DISABLE_RDD_SANDBOX=1 MOZ_DISABLE_GMP_SANDBOX=1` (CI задаёт их только тестовому процессу). Это не настройка расширения и не влияет на браузер пользователя. Тестовые страницы работают на loopback, профиль удаляется после прогона.
