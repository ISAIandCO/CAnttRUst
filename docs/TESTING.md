# Проверка

Локальный обязательный набор:

```bash
npm ci
npm run build:firefox
npm run check:reproducible
```

`build:firefox` включает проверку TypeScript, unit-тесты, сборку, валидацию CA/CT-политик, сканирование пакета и `web-ext lint` с предупреждениями как ошибками.

Перед релизом вручную проверьте распакованную сборку через `about:debugging`:

1. Обычный HTTPS-сайт с другой цепочкой открывается без вмешательства.
2. Цепочка через защищаемый CA вне `.ru/.su/.рф` показывает предупреждение.
3. Та же цепочка в разрешённой зоне без подходящего встроенного SCT блокируется.
4. «Продолжить один раз» разрешает ровно повторный переход в той же вкладке.
5. «Всегда разрешать этот хост» создаёт только exact-host запись; соседний поддомен остаётся защищён.
6. В приватном окне событие и bypass не пересекаются с обычным окном.
7. Экспорт/импорт настроек не принимает IP, URL и файл больше 256 KiB.

Для релизного workflow дополнительно проверьте SHA-256, версию `manifest.json` внутри XPI и факт подписи Mozilla в `about:addons`.
