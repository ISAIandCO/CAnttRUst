# Инварианты безопасности

1. Совпадение CA выполняется только по SHA-256 полного DER и не зависит от отображаемого имени.
2. После совпадения CA неопределённость проверки не должна молча разрешать переход.
3. До совпадения CA сбой дополнительной проверки не должен ломать обычный веб.
4. Разрешённая зона совпадает только с самой зоной или её DNS-поддоменом.
5. IP и `localhost` не проходят зональную проверку и не попадают в постоянный allowlist.
6. SCT считается действительным только после проверки подписи, ключа, алгоритма и интервала лога.
7. `temporal_interval` CT-лога применяется к `notAfter` сертификата; отдельно SCT timestamp не может быть позже `notAfter` или более чем на сутки в будущем.
8. Одноразовый обход потребляется один раз и совпадает по вкладке, incognito, хосту и полному URL.
9. Непривилегированная веб-страница не может читать событие блокировки или менять настройки через messaging.
10. Итоговый пакет не содержит удалённых скриптов, `eval` или `new Function`.

11. SCT отклонённого CT-лога не засчитывается; для usable/readonly/retired проверяется граница времени статуса.
12. Автоматический монитор готовит изменения для рассмотрения, но не сливает PR и не удаляет прежние корневые отпечатки.
13. Метаданные источника не вызывают выпуск без изменения эффективной политики; ошибка скачивания не подменяет политику пустым списком.
