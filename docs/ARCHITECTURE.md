# Архитектура

CAnttRUst — Firefox WebExtension Manifest V2 без удалённого кода.

1. Постоянный background-скрипт перехватывает `onHeadersReceived` только для HTTPS `main_frame`.
2. `getSecurityInfo()` возвращает Firefox-цепочку сертификатов и DER.
3. Ядро вычисляет SHA-256 каждого DER и ищет защищаемый CA по локальной политике.
4. Если CA не найден, запрос не меняется. Если найден, проверяются точное исключение и DNS-зона.
5. Для разрешённой зоны из leaf-сертификата извлекается встроенный SCT list, восстанавливается precertificate TBSCertificate, затем ECDSA P-256/SHA-256 подписи проверяются по локальному снимку CT-ключей.
6. Отрицательный или неопределённый результат после совпадения CA перенаправляется на локальную страницу предупреждения. Исходный URL остаётся только в памяти background-контекста.

Код разделён по границе платформы: `src/core` не зависит от Firefox, `src/adapters/firefox` получает TLS-данные и применяет решение, `src/state` управляет локальными настройками и краткоживущими событиями, `src/ui` содержит локальные страницы.

В сборку попадают только IIFE-скрипты, локальные HTML/CSS, иконки и зафиксированные JSON-политики. CSP запрещает внешний код и объекты.
